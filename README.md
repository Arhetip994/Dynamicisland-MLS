# Dynamic Island — Расширенная поддержка текстов песен

Модифицированная версия **Dynamic Island для Windows** с поддержкой нескольких источников синхронизированных текстов песен (Apple Music, Musixmatch, LRCLIB), умным переключением провайдеров и плавными анимациями перехода строк.

---

## Что добавлено в этой версии

### 1. Несколько источников текста песен (Мультипровайдерность)
* **LRCLIB** — стандартный бесплатный источник, работает «из коробки» без API-ключа.
* **Apple Music** — точные синхронизированные тексты песен через Paxsenix API.
* **Musixmatch** — огромная база текстов песен через Paxsenix API.
* **Настройка приоритета (Drag & Drop и стрелки)**: В меню *«Настройки → Источники текста»* можно менять порядок источников простым перетаскиванием или стрелками вверх/вниз.
* **Автоматический фоллбек (Fallback)**: Если трек не найден у первого провайдера или произошёл таймаут/ошибка сети, остров автоматически пробует получить текст со следующего источника по списку приоритета.

### 2. Интеграция Paxsenix API
* **Удобный ввод ключа**: Поле ввода API-ключа в меню *«Источники текста»*.
* **Маскировка**: Кнопка переключения видимости ключа («глазок»).
* **Вставка в один клик**: Кнопка вставки ключа напрямую из буфера обмена.
* **Индикатор состояния**:
  * ⚪ *Серый* — LRCLIB (ключ не требуется) либо ключ ещё не введён.
  * 🟢 *Зеленый* — ключ сохранен и готов к работе.
  * 🔴 *Красный* — ошибка авторизации (неверный ключ / HTTP 401).

### 3. Плавные анимации строк
* **Плавный переход строк (`SmoothLyricsTransition`)**: Мягкая и плавная анимация переключения между строками песни в компактном острове и плеере без резких скачков ширины.
* **Плавное появление текста (`SmoothLyricsFadeIn`)**: Мягкое появление текста (Fade In) при начале воспроизведения или переключении трека.
* Отдельные переключатели в меню *«Настройки»* и *«Оформление»*.

---

## Где и как получить Paxsenix API Key

Ключ нужен для работы источников **Apple Music** и **Musixmatch**. Стандартный источник **LRCLIB** работает бесплатно и без ключа.

1. Перейдите на сайт [api.paxsenix.org](https://api.paxsenix.org).
2. Перейдите на страницу входа/регистрации: [api.paxsenix.org/login](https://api.paxsenix.org/login).
3. Создайте аккаунт или войдите в существующий.
4. На бесплатном тарифе (**Free Tier**) в панели управления скопируйте ваш **API Key**.
5. В приложении кликните правой кнопкой мыши по острову → **«Настройки»** → **«Источники текста»**.
6. Вставьте ключ в поле ввода (вручную или нажав кнопку вставки рядом с полем).
7. Индикатор сменит статус на зеленый — теперь тексты будут загружаться из Apple Music или Musixmatch.

## Сборка и запуск

Для сборки требуется [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).

### Запуск в режиме разработки
```bash
dotnet run -c Release
```

### Сборка единого exe-файла
```bash
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:EnableCompressionInSingleFile=true -o publish
```
Собранный файл появится в папке `publish/DynamicIsland.exe`.
