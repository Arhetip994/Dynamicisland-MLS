# Dynamic Island — Расширенная поддержка текстов песен

Модифицированная версия **Dynamic Island для Windows** с поддержкой нескольких источников синхронизированных текстов песен (Apple Music, Musixmatch, LRCLIB), умным переключением провайдеров и плавными анимациями перехода строк.

---

## Что добавлено в этой версии

### 1. Несколько источников текста песен (Мультипровайдерность)
* **LRCLIB** — стандартный бесплатный источник, работает «из коробки» без API-ключа.
* **Apple Music** — точные синхронизированные тексты песен через Paxsenix API.
* **Musixmatch** — огромная база текстов песен через Paxsenix API.
* **Настройка приоритета (Drag & Drop и стрелки)**: В меню *«Настройки → Источники текста»* можно менять порядок источников простым перетаскиванием или стрелками вверх/вниз.
* **Автоматический фоллбек (Fallback)**: Если трек не найден у первого провайдера или произошёл таймаут/ошибка сети, остров автоматически пробует получить текст со следующего источника по списку приоритета.

### 2. Интеграция Paxsenix API
* **Удобный ввод ключа**: Поле ввода API-ключа в меню *«Источники текста»*.
* **Маскировка**: Кнопка переключения видимости ключа («глазок»).
* **Вставка в один клик**: Кнопка вставки ключа напрямую из буфера обмена.
* **Индикатор состояния**:
  * ⚪ *Серый* — LRCLIB (ключ не требуется) либо ключ ещё не введён.
  * 🟢 *Зеленый* — ключ сохранен и готов к работе.
  * 🔴 *Красный* — ошибка авторизации (неверный ключ / HTTP 401).

### 3. Плавные анимации строк
* **Плавный переход строк (`SmoothLyricsTransition`)**: Мягкая и плавная анимация переключения между строками песни в компактном острове и плеере без резких скачков ширины.
* **Плавное появление текста (`SmoothLyricsFadeIn`)**: Мягкое появление текста (Fade In) при начале воспроизведения или переключении трека.
* Отдельные переключатели в меню *«Настройки»* и *«Оформление»*.

### 4. Динамическая аура под бас (Reactive Ambient Glow)
* **Адаптивная пульсация**: Свечение вокруг островка мягко пульсирует по радиусу и прозрачности в такт низким частотам (саб-бас и бочка, 30–150 Гц) воспроизводимой музыки.
* **Физическое сглаживание**: Энергия баса сглаживается через пружину (`Spring`), исключая мерцание и дергания UI.
* **Настройки**: В меню *«Оформление»* добавлены тумблер включения реактивной ауры и слайдер регулировки чувствительности/силы реакции баса.

### 5. Интерактивный буфер обмена (Clipboard Peek & Toast)
* **Отслеживание буфера**: Перехват системных событий копирования через Win32 `AddClipboardFormatListener` без лишней нагрузки на процессор.
* **Умное распознавание**: Остров на 1.8 секунды плавно раскрывается и показывает превью:
  * 📝 **Текст** — компактное превью текста с бейджем.
  * 🌐 **Ссылки** — иконка глобуса, авто-распознавание URL и отображение домена.
  * 🖼️ **Изображения** — миниатюрный thumbnail скопированной картинки с бейджем «PNG» / «Изображение».
  * 📁 **Файлы** — название файла или количество скопированных элементов.
* **Интерактивность**: Клик по островку во время превью открывает скопированную ссылку в браузере или разворачивает текст в уведомление.
* **Фильтрация спама**: Игнорирование пустых значений и повторного копирования одного и того же объекта.

### 6. Шаговая перемотка удержанием (Hold-to-Seek)
* **Быстрый свайп**: Оттягивание острова влево/вправо и быстрое отпускание переключает трек (`Next` / `Previous`).
* **Удержание 3 секунды**: Если зажать и удержать оттянутый остров 3 секунды, срабатывает перемотка на **10 секунд** вперед или назад:
  * Оттягивание в сторону следующего трека — перемотка вперед (`+10 сек`).
  * Оттягивание в сторону предыдущего трека — перемотка назад (`-10 сек`).
* **Непрерывный шаг**: При дальнейшем удержании перемотка продолжается шагами по **10 секунд каждые 0.75 сек**.
* **Тактильный отклик**: На каждом шаге перемотки остров делает физический микро-толчок в пружине (`_leanX.Velocity`), давая тактильное ощущение щелчка.
* **Защита от сброса**: При отпускании кнопки после перемотки трек не переключается.

### 7. Интерактивная навигация и скролл по тексту песни (Click-to-Seek & Scroll)
* **Раздельный скролл (Scroll vs Volume)**: При наведении курсора на блок текста колесико мыши плавно прокручивает строки песни вверх и вниз для удобного просмотра текста, не затрагивая громкость (громкость колесиком мыши по-прежнему регулируется на всех остальных элементах плеера).
* **Скролл мышью (Drag-to-Scroll)**: Текст также можно плавно перетаскивать вверх и вниз зажатием левой кнопки мыши.
* **Перемотка по клику**: Нажатие на любую строку текста песни мгновенно перематывает воспроизведение к метке времени этой строки.
* **Подсветка при наведении (Hover)**: При наведении курсора мыши на непетые строки они плавно становятся ярче (с прозрачности `0.4` до `0.8`), показывая интерактивность.
* **Мгновенная синхронизация**: Полоса прогресса, таймер времени и караоке-анимация сразу переключаются на выбранную строчку, а при отсутствии действий текст через несколько секунд плавно возвращается к текущей поющей строке.

## Где и как получить Paxsenix API Key

Ключ нужен для работы источников **Apple Music** и **Musixmatch**. Стандартный источник **LRCLIB** работает бесплатно и без ключа.

1. Перейдите на сайт [api.paxsenix.org](https://api.paxsenix.org).
2. Перейдите на страницу входа/регистрации: [api.paxsenix.org/login](https://api.paxsenix.org/login).
3. Создайте аккаунт или войдите в существующий.
4. На бесплатном тарифе (**Free Tier**) в панели управления скопируйте ваш **API Key**.
5. В приложении кликните правой кнопкой мыши по острову → **«Настройки»** → **«Источники текста»**.
6. Вставьте ключ в поле ввода (вручную или нажав кнопку вставки рядом с полем).
7. Индикатор сменит статус на зеленый — теперь тексты будут загружаться из Apple Music или Musixmatch.

## Сборка и запуск

Для сборки требуется [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).

### Запуск в режиме разработки
```bash
dotnet run -c Release
```

### Сборка единого exe-файла
```bash
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:EnableCompressionInSingleFile=true -o publish
```
Собранный файл появится в папке `publish/DynamicIsland.exe`.
